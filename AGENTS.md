# Repo Notes for Codex Agents

- The recovered Quest APK is `com.Xigbee.FrankaBot` / `FrankaBotControllerTracking`.
- Use `just adb-status-json` for machine-readable readiness. `just adb-prepare` is the complete idempotent bundle: wait for authorized ADB, wake Quest, enable stay-awake, repair reverse ports, close blocking Meta panels, soft-focus FrankaBot, and verify XR foreground. `just adb-focus` never restarts it; `just adb-restart` is the explicit last resort. Never add automatic app restarts to a heartbeat or reconnect path.
- If pose frames become exact `0,0,0` while the Quest is visibly awake, suspect Meta/Oculus system UI focus stealing rather than a network bug. Inspect status, then use `just adb-focus` before considering `just adb-restart`.
- Named profiles are saved under `${QUEST_CALIBRATION_DIR:-~/.config/quest-trajectory-recorder/calibrations}`. Legacy checkout profiles are readable for migration only. Use `just calibrate <profile>` or foreground `just source <profile>` here; complete sessions are owned by whichever downstream backend subscribes to the canonical stream. This repository must not contain backend repository paths or names, task names, feedback/UI code, downstream commands, or complete-session supervision.
- Calibration is page-first: `just calibrate <profile>` may return with the editor ready while Quest is offline. The managed task waits for ADB and attaches the device without restarting an already-running FrankaBot; use `just status-json` to distinguish page readiness from device readiness.
- The source must mark invalid tracking and stop publishing motion targets when raw input is stale. Native workspace, action, and reacquisition policy belongs to consumers and must not be added here.
