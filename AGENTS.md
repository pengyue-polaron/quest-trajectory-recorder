# Repo Notes for Codex Agents

- The recovered Quest APK is `com.Xigbee.FrankaBot` / `FrankaBotControllerTracking`.
- Use `just adb-status-json` for machine-readable readiness. `just adb-prepare` repairs reverse ports and soft-focuses FrankaBot; `just adb-focus` never restarts it; `just adb-restart` is the explicit last resort. Never add automatic app restarts to a heartbeat or reconnect path.
- If pose frames become exact `0,0,0` while the Quest is visibly awake, suspect Meta/Oculus system UI focus stealing rather than a network bug. Inspect status, then use `just adb-focus` before considering `just adb-restart`.
- Named profiles are saved as untracked local files at `calibrations/<profile>.json`. Use `just calibrate <profile>`, `just forcevla <profile>`, or `just maniskill <profile> <task>`; each command returns only when its managed task is ready. Use `just status-json` for the complete machine-readable health snapshot and `just stop` to close whichever task is active. These lifecycle commands already own readiness, PID, log, and child-process checks; do not repeat them manually unless a command fails. The scripts below the Justfile are implementation details.
- Physical collection must fail closed on stale/invalid target data. Do not weaken watchdog, reacquisition, workspace, or action limits merely to mask latency; use the published backend loop and view age to locate the slow stage first.
